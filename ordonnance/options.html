⚠️ Firefox détecté :
Si vous utilisez Firefox avec le protocole file://, les données ne seront pas partagées automatiquement avec ord.html.
Solutions :
  • Utilisez un serveur local (ex: python -m http.server 8000)
  • Ouvrez ord.html après avoir importé les données
  • Cliquez sur le bouton d'actualisation dans ord.html
